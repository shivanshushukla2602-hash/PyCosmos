## 🌟 What is PyCosmos?

**PyCosmos** is a state-of-the-art interactive Python engineering platform that eliminates the fragmentation of learning Python. Instead of switching between scattered tutorials, disconnected coding sandboxes, static PDF cheatsheets, and question repositories, **PyCosmos unifies the entire Python ecosystem into a cohesive, high-performance web experience**.

Whether you're examining bytecodes, tuning async event loops, querying cloud APIs, or training neural networks, PyCosmos provides the environment, visual feedback, and verifiable milestones to master every layer of Python.

## ⚡ WASM Compiler & Interactive Sandbox

PyCosmos integrates **CPython 3.12** directly inside the web browser via WebAssembly (Pyodide):

```python
# Execute directly in PyCosmos — instant client-side execution!
from dataclasses import dataclass
import sys

@dataclass
class CosmosNode:
    name: str
    stage: int
    unlocked: bool = True

node = CosmosNode("Async Engine", 5)
print(f"Node: {node.name} [Stage {node.stage}] • Python {sys.version.split()[0]}")
```

- **Standard I/O Redirection**: Captures `sys.stdout` and `sys.stderr` in real-time.
- **Traceback Cleaner**: Strips WebAssembly execution harnesses for clean, beginner-friendly error messages.
- **Zero Server Overhead**: 100% of user code executes safely in an isolated browser sandbox.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Quick Setup

```bash
# 1. Clone the repository
git clone https://github.com/shivanshushukla2602-hash/PyCosmos.git

# 2. Navigate to project root
cd PyCosmos

# 3. Install dependencies
npm install

# 4. Launch development server
npm run dev
```

Visit `http://localhost:5173` to explore PyCosmos in your browser!

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
